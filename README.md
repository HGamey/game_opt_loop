# game_opt_loop

移动端图形渲染能效与画质自主优化 Harness。

结合大模型探索与自动化真机评测实验台（phonefarm），构建面向移动图形渲染管线的闭环优化 Harness。在满足物理开销与画质约束的前提下，自主探索、变异、验证并筛选轻量 GPU 着色器算子，辅助游戏在移动设备上实现帧率稳定性提升与整机能效优化。

---

## 核心能力与优化方向

系统面向移动端图形渲染管线，提供统一的算子变异、安全门禁、真机部署与统计裁决闭环 Harness。目前支持及规划的方向包括：

1. **分辨率重构**：低分辨率输入下的边缘重构与自适应细节恢复，降低渲染管线计算负载。
2. **时序插帧**：基于双向运动估计的过渡帧生成，平滑时序帧率。
3. **着色器极简化**：对高负载后处理进行等效简化与精度蒸馏，消除指令冗余。
4. **自适应锐化**：低开销微观边缘与对比度增强。

---

## 模块分工

- **game_opt_loop（本仓库）**：算法探索与演化 Harness。负责多赛道模板管理、静态安全防爆检查、LLM 算子变异生成及 Pareto 优胜档案维护。
- **phonefarm（外部底座）**：真机物理测试与环境控制 Harness。负责设备连接、确定性脚本回放、硬件功耗与帧时遥测、统计学显著性裁决及现场原子还原。

---

## 快速开始

```bash
# 1. 运行本地完整测试
cargo test

# 2. 离线验证：不连设备快速跑通闭环
cargo run -- --track sr --generations 3 --children 4 --dry-run --no-llm

# 3. 指定赛道进行探索（可选 sr / frame_gen）
cargo run -- --track frame_gen --generations 3 --children 4 --dry-run
```
